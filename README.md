# Thailand investor screening demo

A browser-only walkthrough of the proposed investor-screening operating model: question-specific request routes, source-backed answers, firm-level triage, and a human decision. It includes two fictional cases and four illustrative pilot arms in English and Thai.

All cases and source replies are fictional. The site does not connect to SDEP, NDID, banks, registries, or other live systems. It collects no personal data and reports no pilot findings. Route choices and mock outputs are for discussion only.

Open the demo at <https://luengnat.github.io/oecd-demo/>.
